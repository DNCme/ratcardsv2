# RatCardsV2

Discord bot for collecting cards with amethyst drops, marketplace auctions, and full profile customization.

## Features

- **Card Collection** — Pull random cards, collect by rarity, and hunt for ultra-rare amethyst cards
- **Mystery Boxes** — Open boxes for a chance at amethyst cards with varying odds
- **Amethyst Marketplace** — Trade amethyst cards with a 10-minute auction system and bidding
- **Gambling** — Spin the wheel with `/dep` and choose your multiplier
- **Profile Customization** — Set custom titles, colors, banners, bios, and pin a card to your profile
- **Leaderboard** — Compete with other players for the top spot

## Commands

| Command | Description |
|---------|-------------|
| `/roll` | Pull a random card |
| `/cards [rarity] [amethyst]` | Browse your collection with filters |
| `/collection [rarity]` | Overview by rarity |
| `/boxes` | Open a mystery box |
| `/marketplace` | View amethyst card listings |
| `/sell` | Instant sell |
| `/buy-listing [id]` | Buy a marketplace listing |
| `/dep [amount]` | Spin the wheel |
| `/profile [@user]` | View a user profile |
| `/stats [@user]` | Detailed statistics |
| `/set-title` | Set a purchased title |
| `/set-color` | Set a purchased color |
| `/set-banner` | Set a purchased banner |
| `/set-bio` | Set your profile bio |
| `/pin-card` | Pin a card to your profile |
| `/leaderboard` | Top players |
| `/help` | Full command list |
